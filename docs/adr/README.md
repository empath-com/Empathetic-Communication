# Architecture Decision Records

This directory stores Architecture Decision Records (ADRs) for cross-cutting technical decisions.

## ADR index

- [ADR-0001](./ADR-0001-shared-router-pipeline.md): Shared request pipeline for role routers
- [ADR-0002](./ADR-0002-structured-logging-standard.md): Structured logging standard for runtime services
- [ADR-0003](./ADR-0003-api-contract-governance.md): API contract governance and change policy

## Lifecycle

- `Proposed`: Draft decision for team review.
- `Accepted`: Agreed and actively implemented.
- `Superseded`: Replaced by another ADR.
- `Deprecated`: No longer used, retained for context.

## ADR format

Use [TEMPLATE.md](./TEMPLATE.md) for new ADRs.
